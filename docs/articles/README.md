# Artigos e Referências

Esta pasta reúne os artigos científicos, normas e especificações utilizados como suporte teórico e metodológico do projeto ISCTE Schedule Manager.

## Referências

- `REF01_Schaerf_1999_Automated_Timetabling.pdf` — revisão dos principais problemas e métodos de geração automática de horários.
- `REF02_University_Course_Timetabling_Survey_IEEE_2021.pdf` — revisão recente das abordagens aplicadas ao problema de horários universitários.
- `REF03_OudeVrielink_2019_Systematic_Review.pdf` — revisão sistemática sobre métodos de otimização de horários.
- `REF04_University_Course_Timetabling_Solver_Evolution_2016.pdf` — evolução e avaliação de métodos de resolução do problema de horários universitários.
- `REF05_ISO25010_Quality_Model_2011.pdf` — modelo de qualidade utilizado como referência para a avaliação da solução.
- `REF06_BPMN_2_0_OMG_2011.pdf` — especificação da notação BPMN 2.0 utilizada na modelação dos processos.
- `REF07_UML_2_5_1_OMG_2017.pdf` — especificação UML utilizada como referência para a modelação do sistema.
- `REF08_IEEE830_Software_Requirements_Specification_1998.pdf` — referência para a identificação e documentação dos requisitos de software.

## Utilização no Projeto

Estas referências apoiam:

- a definição do problema de otimização de horários;
- a escolha dos algoritmos Greedy, Simulated Annealing e NSGA-II;
- a definição das restrições e métricas de qualidade;
- a modelação dos processos e da arquitetura;
- a documentação dos requisitos da aplicação.
