# Requisitos

Esta pasta contém a especificação dos requisitos do ISCTE Schedule Manager.

Os requisitos foram definidos com base no enunciado do projeto, nos processos representados em BPMN, no modelo de otimização descrito no relatório e nas funcionalidades previstas para o protótipo.

## Conteúdo

- `requirements.md` - objetivo, âmbito, perfis de utilizador, requisitos funcionais, requisitos não funcionais e limitações do protótipo.

O documento segue uma estrutura simplificada inspirada na norma IEEE 830 e adequada ao âmbito académico do projeto.
