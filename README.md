# ISCTE Schedule Manager

## Descrição

Projeto desenvolvido no âmbito da unidade curricular de Otimização e Decisão em Engenharia de Software.

O objetivo deste projeto é desenvolver uma solução para otimização e gestão de horários académicos, permitindo reduzir conflitos de alocação, melhorar a utilização das salas e apoiar a tomada de decisão por parte dos diferentes intervenientes do processo académico.
