# Protótipo

## ISCTE Schedule Manager

O protótipo funcional do projeto está disponível em:

[ISCTE Schedule Manager](https://claude.ai/artifact/TuSZssVpmWrEw1uxN1wHP4)

## Objetivo

O protótipo demonstra a aplicação das abordagens de otimização desenvolvidas no projeto e permite validar os principais processos de gestão de horários académicos.

Inclui:

- geração e avaliação de horários;
- Greedy + Simulated Annealing;
- NSGA-II;
- configuração de regras e pesos;
- identificação de conflitos e violações;
- comparação de horários;
- resultados experimentais;
- diferentes perfis de utilizador;
- aprovação, publicação e pedidos de alteração.

## Limitações

O protótipo é executado integralmente no navegador e constitui uma prova de conceito académica.

Não possui um servidor próprio, autenticação institucional, persistência centralizada ou suporte multiutilizador concorrente.
